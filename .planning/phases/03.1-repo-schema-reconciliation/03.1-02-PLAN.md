<objective>
Backfill the 17 migration directories that live ONLY on the EC2 filesystem (and in EC2 prod DB `_prisma_migrations`) into the local clone's `backend/prisma/migrations/` tree. Use a single tarball+scp recipe to preserve byte-for-byte content (critical for Prisma checksum validation during a later `prisma migrate deploy`).

Backfilling them locally restores the canonical migration tree.
