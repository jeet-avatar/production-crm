Add new endpoint to `routes/apollo.ts`:

```typescript
router.post('/send-personalized-campaign', async (req, res, next) => {
  try {
    const { contactIds, templateId, mode = 'preview' } = req.body;
    // mode: 'preview' = generate first contact only and return (don't send)
    //       'send'    = generate all + dispatch via Resend

    const template = await prisma.emailTemplate.findUnique({ where: { id: templateId } });
    if (!template) return res.status(404).json({ error: 'template_not_found' });

    if (mode === 'preview') {
      const firstContact = await prisma.contact.findUnique({ where: { id: contactIds[0] } });
      if (!firstContact) return res.status(404).json({ error: 'contact_not_found' });

      // Cache check: re-use existing PREVIEW_GENERATED record for this (contactId, templateId)
      const cached = await prisma.personalizedEmailSend.findFirst({
        where: { contactId: firstContact.id, templateId, status: 'PREVIEW_GENERATED' },
      });
      if (cached) return res.json({ preview: cached, cached: true });

      const result = await personalizeContactWithClaude(firstContact, template);
      const saved = await prisma.personalizedEmailSend.create({
        data: {
          contactId: firstContact.id,
          templateId,
          personalizedSubject: result.subject,
          personalizedHtml: result.html,
          status: 'PREVIEW_GENERATED',
          ...result.telemetry,
        },
      });
      return res.json({ preview: saved, cached: false });
    }

    // mode === 'send' — full dispatch
    const results = [];
    for (const contactId of contactIds) {
      const contact = await prisma.contact.findUnique({ where: { id: contactId } });
      const personalized = await personalizeContactWithClaude(contact, template);
      // Dispatch via Resend...
      const sent = await prisma.personalizedEmailSend.create({
        data: { contactId, templateId, personalizedSubject: personalized.subject, personalizedHtml: personalized.html, status: 'SENT', sentAt: new Date(), ...personalized.telemetry },
      });
      results.push(sent);
    }
    res.json({ sent: results.length, results });
  } catch (e: any) {
    next(e);
  }
});
```

**🛡 Sara / Resend guards (MANDATORY — same as 04-01):**

The dispatch in `mode === 'send'` MUST use `from: APOLLO_FROM_EMAIL` (the `Sara <sara@techcloudpro.com>` constant from 04-01) — NOT arbitrary sender from request body. The Resend client is the same singleton initialized in 04-01 at module load (do not create a new `new Resend()` here). If a request body includes `fromEmail`, log a warning and ignore.

The `personalizeContactWithClaude` output `subject` + `html` are passed to `resend.emails.send` along with `from: APOLLO_FROM_EMAIL` + `reply_to: 'sara@techcloudpro.com'`. The personalization layer changes the BODY content per contact, not the sender identity.

**Rate-limit consideration:** the `for (const contactId of contactIds)` loop dispatches sequentially. Each Claude call takes 5-15s + each Resend send is ~200ms. For a batch of 50 contacts that's 5-15 minutes total — well within Resend's burst limits. If user requests a batch > 100 contacts, return a 400 with `{ error: 'batch_too_large', message: 'Max 100 contacts per send to protect Resend account quality score.' }` — this is the Sara-protection cap.
