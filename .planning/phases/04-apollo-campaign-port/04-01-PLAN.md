**Required endpoints:**

`POST /api/apollo/import` — Body: `{ filters, apiKey, enrich?: boolean, limit?: number }`. Calls `searchPeople(filters, apiKey, {limit})`, optionally `enrichPerson` per result. Saves Contact + Company rows with `source='apollo'`, `stream=classifyStream(person)`, `apolloPersonId`, `apolloRawData`. Returns `{ imported: number, contacts: Contact[] }`.

`POST /api/apollo/send-campaign` — Body: `{ contactIds: string[], stream?: string, fromEmail?, fromName? }`. For each contact:
1. Find template by category `Stream:<contact.stream>` in email_templates
2. If not found, find by `Stream:Other`
3. If still not found, use `HARDCODED_FALLBACK` body
Renders template with `{{firstName}}` etc placeholders, dispatches via Resend SDK (separate `process.env.RESEND_API_KEY`, separate from existing SES path in `routes/campaigns.ts`). Returns `{ sent: number, failed: number, results: [] }`.

**Auth:** Both endpoints use `router.use(authenticate)` at top.

**ApolloAuthError handling:** Catch `ApolloAuthError` in `/import` handler and return 401 with `{ error: 'apollo_key_invalid', message: 'Your Apollo API key is invalid or expired. Get a new one from app.apollo.io.' }`.
