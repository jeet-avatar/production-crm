Implementation details (match 04-RESEARCH.md Section 3 exactly):

**searchPeople body:**
- Build `payload` object: `{ page: filters.page ?? 1, per_page: filters.perPage ?? 25 }`
- Conditionally set: `person_titles`, `person_locations`, `q_organization_keyword_tags`, `q_organization_domains_list`
- If both `minEmployees` and `maxEmployees` provided: `payload.organization_num_employees_ranges = [\`${min},${max}\`]`
- POST to `${APOLLO_BASE}/mixed_people/api_search` with headers `X-Api-Key`, `Content-Type: application/json`, `Cache-Control: no-cache`, timeout 60000ms
- On axios 401 → throw `new ApolloAuthError('Apollo key invalid or expired')`. Do NOT throw on 200.
- Return `response.data`

**enrichPerson body:**
- POST to `${APOLLO_BASE}/people/match` with body `{ id: personId, reveal_personal_emails: false }`, timeout 30000ms
- On any error: log warn `Apollo enrich failed for ${personId}: ${err?.response?.status} ${err?.message}` and return `null`
- On success: return `response.data?.person ?? response.data ?? null`
- Never throw — caller treats null as "skip this record"

**isEmailLocked body:**
